# cue

Installs the [Cue](https://github.com/cue-lang/cue) language.

## Example Usage

```json
"features": {
    "ghcr.io/blabtm/features/cue:1": {}
}
```

## Options

| Options Id | Description | Type | Default Value |
|-----|-----|-----|-----|
| version | Select or enter a cue version to install | string | 0.16.1 |
