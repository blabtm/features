# dagger

Installs the [Dagger CLI](https://github.com/dagger/dagger) .

## Example Usage

```json
"features": {
    "ghcr.io/blabtm/features/dagger:1": {}
}
```

## Options

| Options Id | Description | Type | Default Value |
|-----|-----|-----|-----|
| version | Select or enter a Dagger CLI version to install | string | 0.21.7 |
