# gcx

Installs [gcx](https://github.com/grafana/gcx) command line tool.

## Example Usage

```json
"features": {
    "ghcr.io/blabtm/features/gcx:1": {}
}
```

## Options

| Options Id | Description | Type | Default Value |
|-----|-----|-----|-----|
| version | Select or enter an gcx version to install | string | latest |
