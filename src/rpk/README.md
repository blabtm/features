# rpk

Installs [rpk](https://docs.redpanda.com/current/get-started/rpk/) command line tool.

## Example Usage

```json
"features": {
    "ghcr.io/blabtm/features/rpk:1": {}
}
```

## Options

| Options Id | Description | Type | Default Value |
|-----|-----|-----|-----|
| version | Select or enter an rpk version to install | string | latest |
